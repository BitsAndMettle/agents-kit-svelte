Primitives: added the action components `Button`, `IconButton`, `ButtonGroup`, `Toggle` and `ToggleGroup`. Buttons cover five variants, four sizes, a pill shape, icon slots and a loading state that keeps the button's width and stays focusable; they render a link when given an `href`. `IconButton` requires an accessible `label`. `Toggle` and `ToggleGroup` bind their state, and `ToggleGroup` is built on the headless group pattern, so arrow keys, Home and End move focus.
