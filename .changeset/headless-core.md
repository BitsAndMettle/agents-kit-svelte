New `agents-kit-svelte/headless` entry: accessible behaviour without markup or styles, built on `<dialog>`, `popover` and CSS anchor positioning with no runtime dependencies. Patterns: `Dialog` (and alert dialogs), `Popover`, `Menu` (submenus, checkbox and radio items, context menus), `Select`, `Combobox`, `Listbox`, `Tooltip` (shared delay), `Tabs`, `Accordion`, `RadioGroup`, `ToggleGroup`, plus `ListNav` for custom composites. The peer dependency on Svelte rises to `^5.29.0` (attachments in spreads).
